## 0. 核心结论（先看这三条）

### 结论 1：导师的要求今天已经可以满足了，而且我今天就验证过了

`deepgem_feat_v3_titan/` 里躺着 **421 张 TCGA-LUAD 切片的 TITAN slide 级特征（768 维）**，
`data/MC3/9gene_panel_LUAD.csv` 里是 **421 例的 9 基因标签**。

我直接用这两份东西跑了一个 9-head 多任务 MLP + 5-fold CV：

| 指标 | 实测值 |
|---|---|
| 训练矩阵 | X = (421, 768)，**总内存 1.29 MB** |
| 设备 | **纯 CPU，未使用 GPU** |
| 耗时 | **18.2 秒** |
| 可评估基因 | 7 个（ERBB2 n=6、NRAS n=3 样本不足） |
| 逐基因 OOF AUC | EGFR **0.754** / TP53 **0.745** / PIK3CA 0.656 / KRAS **0.652** / ROS1 0.650 / BRAF 0.483 / ALK 0.469 |
| **mean AUC** | **0.630**（MLP）／**0.633**（LogisticRegression 参照） |

**这份结果比项目现有的 83-case mean AUC 0.532 更好，而且是零成本、零 GPU、18 秒跑出来的。**
脚本已存于 `.tmp/run_cpu_baseline.py`，特征与标签已导出为 `.tmp/X_titan421.npy` / `.tmp/Y_9gene421.npy`。

**结论：算力不是这个项目的瓶颈。从来都不是。** 瓶颈是数据组织方式和实验口径混乱。

## 2. 数据获取方案

### 2.1 核心判断：公开数据这条路不只是省钱，是更安全

调研时发现了一个值得高度重视的信号：

**PathGene**（arXiv 2506.00096）——中南大学湘雅二院 + TCGA-LUAD 448 例，
做的是**和本项目几乎完全相同的任务**（肺癌驱动基因突变 + 外显子位点预测），
是本项目最直接的对标物。

**这篇论文已于 2025-09-24 和 2025-11-27 两次从 arXiv 撤稿，撤稿原因明确写着：**
> `Withdrawn due to issues related to data permissions/ethics`

**这直接印证了导师对数据的谨慎态度是对的。** 医院数据的伦理审批、数据使用授权、跨机构共享，
是真实存在、会致命的风险。相比之下：
- TCGA / CPTAC 是 NIH 资助的公开数据，**有 Data Use Certification，学术使用完全合规**
- 论文引用时数据来源清晰、可复现、审稿人不会质疑
- 学位授予单位对数据合规性的要求天然满足

**所以：公开数据路线在省钱之外，还额外降低了毕业和投稿的合规风险。这是应该坚持公开数据路线的最强理由。**

## 3. 算力方案

### 3.1 首选方案：零 GPU（推荐，且已验证）

**原理：把重计算前移一次，之后全部冻结。**
病理基础模型的特征提取是整条 pipeline 里唯一吃 GPU 的环节（实测 CONCH v1.5 约 1.34 s/patch）。
一旦拿到 slide 级或 patch 级特征，后续的 MIL 训练就是一个几 MB 的矩阵运算。

| 环节 | 算力需求 | 本项目现状 |
|---|---|---|
| 切片解码 / patch 切分 | CPU + 磁盘 | 已打通 |
| **patch 特征抽取** | **GPU（重）** | **已用预提取特征绕过** ✅ |
| slide 级聚合 | **CPU（轻）** | ✅ 已有 |
| MIL 头训练 | **CPU（轻）** | ✅ 18.2 秒跑完 |
| 超参搜索 / 5-fold × N seed | **CPU（轻）** | ✅ 分钟级 |
| 外部验证推理 | **CPU（轻）** | ✅ |

**8 GB 显存的 RTX 5070 只需要承担一件事：如果你想自己抽特征。**
而公开的预提取特征库（UNI2-h-features / TITAN）已经把这件事替你做完了。

| 代码 | https://github.com/Luoxd1996/nnMIL |
| 许可 | 需确认（arXiv 论文，检索中未确认 LICENSE 类型） |

**解决的核心问题**：传统 MIL 因每张 WSI 的 patch 数不固定，**训练时 batch size 只能设为 1**，
这直接导致无法使用现代优化策略，是 MIL 领域公认的核心瓶颈。

**nnMIL 的解法**：
1. **patch 级随机采样** → 变长 bag 变定长 sub-bag → **可用大 batch + 平衡 mini-batch 训练**
2. **feature 级随机采样** → 进一步降显存
3. **轻量聚合器 + sliding-window 推理** → 集成多个重叠子采样的预测
4. **原生支持不确定性估计** → 可做"低置信度转人工复核"，临床落地的关键卖点

**实测效果**：40,000 张 WSI、35 个临床任务、4 个病理基础模型上**一致优于现有 MIL 方法**；
分子标志物检测（9 个生物标志物：ER/PR/HER2/BRAF/KRAS/IDH/WGD/TMB/非整倍体）上，
**nnMIL + Virchow2 取得 mean AUC 0.795，超过 ABMIL 和 DSMIL 3.3–4.1%（p<0.001）**。

**对本项目的价值**：
- 8 GB 显存的直接解药（采样后定长，显存可控）
- 有开源代码，可直接跑
- **不确定性估计 → 天然对接"9 个概率 + 置信度 + 证据区域"的临床输出需求**
- 论文可引用（2025-11 arXiv，时效性好）

## 5. 技术路线设计（4 条，按推荐度）
